# Logos

- `qualys-logo-full-rgb.svg` — the primary logo: shield in #ED2E26 (Qualys Red) with a white Q, wordmark in #262626 (Charcoal). Use on white and warm off-white. On charcoal or blue grounds render it all-white (`filter: brightness(0) invert(1)`), as the source does.
- `qualys-logo-reversed.svg` — the reversed logo from the Figma Cards page: shield in #ED2E26 with a near-white Q, wordmark in white. Use on Charcoal and on the blue gradient (inline promo cards), 37px tall.
- `qualys-shield.svg` — the shield mark alone, cropped from the primary logo file (same paths, same inks). For square or tight placements.
- Never redraw, recolor or re-letter any of these files.

# General Icons

The three "icon / general" line icons from the Figma Cards page, 56 × 43 with a 1.5px line, single ink in `currentColor` (in an `<img>` they render black). They mark the hub cards on Charcoal: use them through `InlinePromoCard` (`icon="general-events"`) or the `Icon` component so they take `icon-inverted`.

- `icon-general-events` — a calendar, for the Events Center.
- `icon-general-webinar` — a presenter on a laptop, for webinars.
- `icon-general-resource` — a gear, for the Resource Center.

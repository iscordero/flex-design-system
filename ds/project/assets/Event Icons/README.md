# Event Icons

The five event-type icons from the Figma Tagging System, 24 × 24, each in its own single ink (they keep their colour in an `<img>`). In product UI use the EventType component, which pairs each icon with its label.

- `icon-event-qualys` — Qualys Event, the Qualys shield in `event-qualys` (Qualys Red, #ED2E26).
- `icon-event-webinar` — Webinar, `event-webinar` (Qualys Blue, #2683ED).
- `icon-event-industry` — Industry Event, `event-industry` (Charcoal, #262626).
- `icon-event-speaking` — Speaking Engagement, `event-speaking` (#6C49D1).
- `icon-event-training` — Training, `event-training` (Asphalt, #575757).

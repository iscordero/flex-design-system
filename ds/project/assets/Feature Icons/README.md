# Feature Icons

The 19 feature icons from the Figma component set `icon / feature`: two-tone blue illustrations on a 56 × 56 artboard, drawn in fixed colors (blue gradients, #2E8BE0, #9BC0E0 and white), so they look the same in an `<img>` and must not be recolored.

- Names: `feature-ai`, `feature-agentic-ai`, `feature-application`, `feature-applications`, `feature-assets`, `feature-cloud`, `feature-communication`, `feature-compliance`, `feature-configure`, `feature-detect`, `feature-eliminate`, `feature-measure`, `feature-prioritize`, `feature-remediation`, `feature-response`, `feature-risk`, `feature-threat`, `feature-vulnerability`, `feature-web-application`.
- In a Drawer they show in a 32px box beside the title (pass the file's URL as `icon`).
- Several icons include white details, which only show on a ground that isn't white.
- Figma spells one variant "Priroritize"; the file here is `feature-prioritize`.
